Resolución del ejercicio N°17 de la unidad 3 de programación 2.
Este programa encapsula la información de una cuenta de fidelidad y su saldo oculto de puntos, permitiendo calcular de manera interna las recompensas obtenidas a partir de los montos de compra y ejecutar transacciones de canje que validan la suficiencia de los fondos antes de realizar cualquier descuento.
